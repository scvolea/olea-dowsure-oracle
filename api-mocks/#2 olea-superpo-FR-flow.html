DOWSURE / OLEA DATA EXCHANGE

Super PO Data Flow

After obtaining financing approval from Dowsure, a merchant draws on its available credit. Dowsure prepares order-level financing records from seller-authorized Amazon Selling Partner API (SP-API) Finances Transactions data. Once Olea confirms the related orders, Dowsure aggregates them into a Super PO financing request.

RelationshipOne financing drawdown → one Super PO identifier → multiple order-level records
01 / 03

Origin of the Financing Request

Request origin: The merchant applies for financing and obtains approved credit from Dowsure. Each subsequent drawdown creates the record used in this flow.

Trigger: The merchant initiates the drawdown on the Pay In page.

Olea eligibility: After the drawdown, the record must meet lender routing and Olea credit approval conditions before Dowsure retrieves related orders for submission.

02 / 03

Order Source and Coverage Check

Scheduled processing: Dowsure periodically checks eligible drawdowns and starts Olea order preparation after lender routing.

Transaction source: Seller-authorized Amazon SP-API Finances Transactions. Order identifiers come from transaction references; amounts, currencies, shipping fees, and posting dates come from transaction data.

Relationship: One drawdown may be linked to multiple orders. Each order is confirmed through the FR Invoice process.

Order Coverage Calculation

EligiblePrincipal(i) = round((OrderAmount(i) - Shipping(i)) x (1 - ReturnRate) x DisbursementRate x DilutionRate, 2)

Standard: DisbursementRate = 1.00.

Deferred: DisbursementRate = min(1.00, (Q1 Disbursements + Q2 Disbursements) / (Q1 Sales + Q2 Sales)); if total sales are 0, the rate remains 0.

Target = remaining financing amount; select orders until sum(EligiblePrincipal(i)) >= Target.

FundedAmount(i) = min(EligiblePrincipal(i), remaining Target)

Example: Target = 100; eligible principal = 40 + 35 + 30 = 105; funded amounts = 40 + 35 + 25 = 100.

If the selected orders do not cover the target, Dowsure does not submit an Olea order batch in that cycle.

03 / 03

Super PO Submission and Confirmation

Super PO data: Super PO identifier, total order amount, total financing amount, currency, buyer, seller, and linked order identifiers.

Completion: ACCEPTED from Olea means the batch was received. The Super PO is confirmed only after final processing succeeds.

Illustrative business flow. No actual order or merchant data is shown. Field definitions and API behavior are subject to the integration specification agreed by both parties.
